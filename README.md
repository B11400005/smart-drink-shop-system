# 智慧飲料店 POS 系統 (NUCLEO-G474RE 期中專題)
解決尖峰時段奧客現場插隊、外送平台爆單與牛奶原料存量預警的嵌入式控制系統。

## 1. 情境故事：誰、在哪、遇到什麼麻煩
飲料店櫃台店員在午後尖峰客潮爆滿時，同時面臨三個麻煩：
1. 現場大排長龍，突遇奧客插隊要求優先點餐。
2. 外送平台訂單不斷湧入，店員手忙腳亂容易漏單。
3. 後場牛奶庫存即將見底，面臨斷貨危機。

## 2. 替身對照：故事裡的模組 ➔ 板上替身
- 系統待機狀態 ➔ PC6 綠燈（恆亮）
- 奧客插隊事件 ➔ PA12 按鈕（按下立即反應，外部中斷 EXTI）
- 奧客插隊警示燈號 ➔ PC8 黃燈（閃爍 3 次，約 1 秒完結）
- 外送訂單大量湧入 ➔ LPUART1 環形緩衝區 Ring Buffer（封包非同步接收）
- 牛奶庫存預警 ➔ PC9 紅燈 (TIM3_CH4 PWM 呼吸漸變，限幅 15000)

## 3. 功能與驗收條件：動作、預期、實測結果
- **奧客插隊功能**：按下 PA12 按鈕 ➔ 預期黃燈閃爍 3 次、綠燈暫熄、紅燈暫停呼吸 ➔ 實測觸發 EXTI15_10 順利完成插隊警示 [Pass]
- **外送平台爆單**：透過 LPUART1 傳入多筆訂單字串 ➔ 預期環形緩衝區依序接收、零漏單 ➔ 實測 rx_head 與 rx_tail 運作正常，遇換行字串成功解析回傳 [Pass]
- **牛奶庫存預警**：監控牛奶水位與觸發預警 ➔ 預期紅燈啟動呼吸燈漸變 ➔ 實測 TIM3_CH4 順利輸出 PWM 脈寬調變 [Pass]

## 4. 用到的技術：第 3 ～ 7 週勾選表 (同投影片)
- **GPIO Output / Input**：PC6 (綠燈)、PC8 (黃燈) 輸出控制；PA12 上拉輸入。
- **EXTI 外部中斷**：PA12 下降沿觸發中斷，搭配 200ms 軟體時間戳防彈跳。
- **Hardware Timer PWM**：TIM3 Channel 4 驅動 PC9 紅燈呼吸燈，脈寬上限限制 15000。
- **LPUART1 通訊與 RXNE 中斷**：波特率 115200 8N1，結合 NVIC 優先級設定。
- **Ring Buffer (環形緩衝區)**：實現背景非同步串口資料接收與佇列排隊，確保零漏單。
- **PLL 時脈設定**：系統全速 170MHz 超頻運算。

## 5. 腳位表：用到的每支腳與用途
- `PC6` = LED_Green (POS 待機指示燈)
- `PC8` = LED_Yellow (奧客插隊急單指示燈)
- `PC9` = TIM3_CH4 PWM (紅燈牛奶庫存預警呼吸燈)
- `PA12` = EXTI15_10 按鍵 (奧客插隊觸發按鈕，內建 Pull-up)
- `PA2 / PA3` = LPUART1_TX / RX (外送平台訂單接收與狀態回傳)

## 6. 建置與執行：開發環境、燒錄步驟、終端機設定、命令
- **開發環境**：STM32CubeIDE v1.13.0 / NUCLEO-G474RE
- **燒錄步驟**：開啟 `smart-drink-shop-system` 專案 ➔ 編譯專案 (Build Project) ➔ 燒錄至開發板 (Run / Debug)。
- **終端機設定**：Baud Rate: `115200`, Data: `8 bit`, Parity: `None`, Stop: `1 bit` (115200 8N1)
- **測試命令**：按下板上 PA12 按鈕觀察黃燈閃爍；或經由 Serial Terminal 發送字串（如 `order1\r\n`）驗收外送接單回傳。

## 7. 程式結構：哪個檔做什麼、ISR 與主迴圈分工
- `Core/Src/main.c`：
  - **主迴圈 (while(1))**：輪詢奧客急單旗標 (`urgent_order_flag`) 執行黃燈閃爍、非同步解析 Ring Buffer 佇列訂單、更新 TIM3 PWM CCR 暫存器實現呼吸燈。
- `HAL_GPIO_EXTI_Callback()` (ISR)：
  - 補捉 PA12 EXTI 中斷，比對 `HAL_GetTick()` 進行 200ms 防彈跳，精簡設旗標後快速返回。
- `HAL_UART_RxCpltCallback()` (ISR)：
  - LPUART1 RXNE 觸發，將傳入字元寫入 `rx_buffer` 環形緩衝區並更新 `rx_head`，開啟下次中斷。

## 9. AI 使用說明：哪段請 AI、您怎麼查核
- **AI 協助章節**：AI 協助規劃 POS 商業情境與程式碼架構重構（如環形緩衝區非同步邏輯與 PWM 限幅控制）。

## 10. 已知限制：哪些用替身、換真貨要改哪裡
- **牛奶庫存感測**：目前以 TIM3 PWM 呼吸燈模擬庫存消耗與預警；若換成真貨（如重量感應器或液位感測器），需改為 ADC 採樣或 I2C 讀取。
- **奧客按鈕防彈跳**：採 200ms 軟體時間戳比對；若現場環境有嚴重硬體彈跳，建議加設外部 R-C 濾波電路。
- **PWM 亮度限幅**：呼吸燈設定 `max_pwm` 限高為 15000 避免過亮；若換成不同規格的發光二極體，需重新微調 TIM3 Prescaler 與 ARR 參數。
